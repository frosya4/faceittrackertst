# Faceit Stats Overlay

## Деплой на Render.com (Облако)

1. Создайте Web Service на Render.
2. Подключите ваш GitHub репозиторий.
3. Команда запуска: `node server.js`.
4. В `overlay.html` замените `apiUrl` на вашу новую ссылку, если используете GitHub Pages.

Оверлей для отображения статистики Faceit в стиле официального дизайна.

## Быстрый старт

### 1. Установка Node.js
Если не установлен, скачайте с https://nodejs.org/

### 2. Запуск сервера
Откройте терминал в папке с проектом и выполните:

```bash
node server.js
```

### 3. Открытие оверлея
В браузере перейдите по адресу: **http://localhost:3000**

## Настройка в OBS

1. В OBS добавьте новый источник: **Browser** (Браузер)
2. Установите размеры: Width = 450, Height = 150
3. В поле URL укажите: `http://localhost:3000/overlay.html`
4. Поставьте галочку **Refresh browser when scene becomes active**
5. Нажмите OK

## Конфигурация

Откройте `server.js` и измените параметры в объекте `CONFIG`:

```javascript
const CONFIG = {
    apiToken: 'ВАШ_ТОКЕН',        // API токен Faceit
    playerNickname: 'DeRoyse',    // Никнейм игрока
    port: 3000                    // Порт сервера
};
```

## Структура данных

Оверлей отображает:
- **ELO** — рейтинг Faceit
- **Level** — уровень (1-10)
- **KDR** — общее соотношение убийств/смертей
- **Win rate (20 матчей)** — процент побед за последние 20 игр
- **Avg. kills / HS** — среднее убийств / процент хедшотов
- **K/D / K/R** — среднее K/D и K/R за последние 20 матчей

## Обновление данных

Данные обновляются автоматически каждые **60 секунд**. Сервер кэширует ответы API на 1 минуту для снижения нагрузки.

## API эндпоинты

- `GET /` — главная страница с оверлеем
- `GET /overlay.html` — HTML оверлей
- `GET /api/stats` — JSON со статистикой игрока

## Примечания

- Для работы требуется действующий Faceit API токен
- Токен уже настроен для игрока **DeRoyse**
- При ошибке подключения оверлей покажет "Ошибка" красным цветом
